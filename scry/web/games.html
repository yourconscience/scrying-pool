Reading the saved games…

A pasted match chat doesn't carry game numbers, but DomBot's !match reply does: paste it whole and the games, the opponent and each player's time come from it. Show reads the games already saved. Load uses your dominion.games tab in Brave and logs in if it has to. It leaves a finished game or an empty table by itself, then takes the tab over until it's done, so don't press it between the games of a match. It won't touch a game in progress against a person.

      Went well and went badly are comparisons from fixed rules, not verdicts: each is a fact with its numbers, and docs/match-review.md says what each rule compares and how often it matched the result over the saved games. Points and decks are rebuilt from the log; tokens aren't split by the card that gave them.
      
  
      Draw luck compares the treasure in your hands on turns 3-12 with what the deck's treasure gives on average. It counts treasure only, so a deck that pays with actions looks unlucky: read it as a hint. A log names only the first seat's hands, unless it merges both seats.

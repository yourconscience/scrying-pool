Get your own profile

  1. Install the app and start it: go install github.com/yourconscience/scrying-pool@latest, then scry web.
  2. Once, export the log grammar from your dominion.games tab: scry bookmarklet -client prints a bookmark; click it, then pbpaste | scry client save.
  3. Load your finished games: the Scry game bookmark on the app's Analyze page for one game, or the capture script for many (see the README), then scry import.
  4. scry db builds an SQLite database of your games; scry site -players "you,friend" builds this page for any host.

Rates count ties as half a win. Opponents' ratings aren't taken into account yet. Only finished games: the dominion.games Terms of Service ban tools that help in games in progress.
